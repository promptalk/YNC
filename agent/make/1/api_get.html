요청 전송 실패 / CORS 제한 발생

지정한 엔드포인트로 HTTP GET 요청을 전송하는 중 오류가 발생했습니다.

원인 및 해결 방법 안내:

1. CORS(교차 출처 자원 공유) 제한: 대상 서버의 헤더에 Access-Control-Allow-Origin: * 설정이 없어 브라우저가 응답 수신을 차단했을 수 있습니다.

2. 우회 테스트: 상단의 버튼을 통해 브라우저에서 직접 URL을 실행해 보세요.

3. 대상 URL이 정상적으로 동작하는지 확인해 주세요.
