## 3. 프론트엔드 (`dashboard.html`)

### 3.1 공통
- Tailwind CDN 기반 **3단 반응형 그리드** (모바일 1단).
- **다크모드**: 헤더 Light/Dark 토글, `localStorage` 저장, 렌더링 전 테마 적용(깜빡임 방지), 캘린더 iframe 반전 필터.
- **CRUD**: 모달로 추가·수정, 삭제는 확인 팝업. 필수값·날짜 순서 검증, 저장 중 버튼 비활성화(중복 제출 방지).
- **로딩 스피너 / Toast**, ESC·배경 클릭으로 모달 닫기.
- 모든 사용자 입력은 HTML 이스케이프 처리(XSS 방지).
- id는 `PRJ_`/`MEM_`/`SAL_`/`TSK_` + 타임스탬프.

### 3.2 모듈
| 모듈 | 구현 내용 |
| :--- | :--- |
| 진행중인 프로젝트 | D-Day 자동 계산, 임박순 정렬, D-3 이내 붉은 배지·카드 강조, 마감 지난 항목은 흐리게 표시하고 뒤로 정렬 |
| 중요 메모 | 핀 카드, 적용 기간 표시, 기간이 지난 메모는 "만료" 배지로 흐리게 표시 |
| 캘린더 | 구글 캘린더 iframe(주간/월간/일정) + 대시보드 자체 "프로젝트·할 일" 월간 달력 (3.4 참고) |
| 구글 태스크 | 빠른 입력(제목·마감일·카테고리), 체크 토글, 목록 필터, 구글 태스크 바로가기 |
| 영업 메모 | 총 예상매출 자동 합산(`₩` 포맷), 중요도(상/중/하) 컬러 배지, 중요도순 정렬 |

### 3.3 데이터 저장 모드
- **로컬 모드**(GAS URL 비움): `localStorage`에 저장, 최초 실행 시 샘플 데이터 생성.
- **Google 연동 모드**: GAS 웹 앱과 `fetch` 통신. 웹 앱 URL은 `DEFAULT_GAS_URL`에 내장, **API 토큰만 설정에서 입력**.
- 헤더 배지로 상태 표시: `💾 로컬 모드` / `🔑 토큰 필요` / `⚠️ 연결 안 됨` / `☁️ Google 연동`, 마지막 동기화 시각 표시.

### 3.4 캘린더 "📋 프로젝트·할 일" 보기 (기본 보기)
**배경:** 구글 캘린더 임베드(iframe)는 일정(Events)만 보여 주고 구글 태스크를 표시하지 않는다. 임베드 URL로는 해결할 수 없어 대시보드에서 직접 그린다.

- 월간 달력(월요일 시작, 6주×7일), 이전/다음/오늘 이동, 오늘 강조.
- **할 일**: 마감일 칸에 칩으로 표시. 완료는 취소선, 마감 지난 미완료는 붉은색. 마감일 없는 할 일은 개수만 안내.
- **프로젝트**: 시작일~마감일을 막대로 표시. 여러 주에 걸치면 주마다 분할(`◂` `▸`), 겹치면 줄을 나눠 배치. 마감 D-3 이내 빨강 / 일반 초록 / 마감 지남 회색. 마감일만 있으면 하루짜리, 기간이 없으면 개수만 안내.
- 할 일·프로젝트 클릭 → 수정 창, 빈 날짜 클릭(또는 Enter/Space) → 마감일이 채워진 할 일 추가 창.
- `📁 프로젝트` / `✅ 할 일` 표시 토글(설정 저장).
- 주간/월간/일정 보기에서는 "임베드에는 태스크·프로젝트가 표시되지 않는다"는 안내 표시.
- 임베드 보기 중에는 iframe을 다시 그리지 않아 깜빡임 없음.
- 한 주에 막대·칩이 많으면 주 높이가 늘어나고 달력 영역이 스크롤된다.

## 4. 백엔드 (`GAS/`)

### 4.1 API
모든 응답은 JSON, 오류는 HTTP 200 + `{ "error": "메시지" }`.

```
GET  <exec URL>?action=list&token=TOKEN
  → { projects, memos, sales, tasks, taskLists, warnings }

POST <exec URL>   (Content-Type: text/plain, 본문은 JSON 문자열)
  { token, action: 'create'|'update'|'delete', module: 'projects'|'memos'|'sales'|'tasks', data }
  → { data }
```
- POST를 `text/plain`으로 보내 CORS preflight를 피한다. (GAS 웹 앱은 OPTIONS 미지원)
- `update`는 전달한 필드만 변경(부분 수정).

### 4.2 동작
| 항목 | 내용 |
| :--- | :--- |
| 인증 | 공유 **API 토큰**(스크립트 속성 `API_TOKEN`). 토큰이 없거나 불일치하면 모든 요청 거부, 서버에 토큰이 미설정이어도 거부 |
| 동시성 | 쓰기는 `LockService`로 직렬화(대기 30초) |
| 시트 | 탭이 없으면 헤더와 함께 자동 생성, 헤더가 스키마와 다르면 명확한 오류. 날짜는 `YYYY-MM-DD` 문자열로 정규화(시트의 Date 객체도 변환). 제목·내용은 일반 텍스트 서식으로 저장해 `=` 입력이 수식으로 실행되지 않음 |
| 검증 | 제목·프로젝트 마감일 필수, 날짜 형식·실존 여부, 시작일 ≤ 마감일, 영업 중요도(상/중/하)·금액(0 이상 숫자). 규칙에 맞지 않거나 중복된 id는 서버가 재발급 |
| 태스크 | id는 `목록id~태스크id`, `category`는 Task List id. 완료 해제 시 완료 시각 제거, 마감일 제거 지원, 목록 이동 시 새 id 반환. 태스크 조회만 실패하면 시트 데이터는 정상 반환하고 `warnings`에 사유 기록 |
| 최초 설정 | `setupToken()`(토큰 발급 + 권한 승인), `resetToken()`, `setupSheets()` |

### 4.3 배포 상태
- 웹 앱 URL 배포 및 토큰 검사 동작 확인 완료(토큰 없이 호출 시 설계된 오류 JSON 응답).
- 웹 앱 URL: `https://script.google.com/macros/s/AKfycbwtR9zq2EB60zYVurah5jhEP-jBYaULvhHaG1RORlOtslUZJM_-fH7XujlVWx1Cq4ls/exec`
- **API 토큰은 사용자가 `setupToken()` 실행 후 대시보드 설정에 입력해야 한다.** (이 문서에는 기록하지 않음)

## 5. 구글 시트 (`dashboard_data.xlsx`)

PRD 5절 스키마와 동일한 3개 탭. 1행 헤더는 영문 키(JSON 키와 동일).

| 탭 | A | B | C | D | E |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `프로젝트` | id | title | content | startDate | endDate |
| `중요메모` | id | title | content | startDate | endDate |
| `영업메모` | id | title | content | priority | amount |

- 날짜 열은 텍스트 서식(500행까지 사전 지정), `priority`는 상/중/하 드롭다운, `amount`는 `#,##0` 숫자 서식, 첫 행 고정.
- 샘플 데이터는 PRD 예시 1건씩.
- 변환 후 시트 ID가 바뀌면 `GAS/Config.gs`의 `DEFAULT_SHEET_ID`를 수정해 다시 배포해야 한다.

## 6. 주요 수정·결정 사항

| 번호 | 내용 | 사유 |
| :--- | :--- | :--- |
| 1 | "모든 사용자" 배포 + **토큰 인증** 채택 (PRD 7절의 "조직 내 사용자 + 로그인 쿠키" 대신) | `file://`로 연 HTML은 인증 쿠키가 전달되지 않을 가능성이 큼. 토큰이 없으면 전부 거부하도록 설계 |
| 2 | `fetch`에서 `credentials: 'include'` 제거 | GAS의 CORS 응답(`Allow-Origin: *`)과 쿠키 전송이 충돌 |
| 3 | 연동 모드에서 불러오기 실패 시 **로컬 샘플 대신 오류 배너** 표시 | 샘플 데이터를 서버 데이터로 오해할 수 있음 |
| 4 | 연결이 안 된 상태에서 저장 차단 | 서버와 화면 데이터 불일치 방지 |
| 5 | 태스크 체크 토글을 낙관적 업데이트 + 실패 시 원복 | 즉각적인 반응과 일관성 |
| 6 | 탭 복귀 시(1분 이상) 자동 새로고침 | 다른 기기·탭의 변경 반영 |
| 7 | 설정 화면에 **🔌 연결 테스트** 추가 | 저장 전에 URL·토큰 검증 |
| 8 | 캘린더 기본 보기를 "프로젝트·할 일"로 변경 | 임베드에는 태스크·프로젝트가 표시되지 않음 |
| 9 | 달력 주(行) 높이를 내용에 맞게 가변화 | 막대·칩이 칸 밖으로 넘치는 문제(테스트 중 발견) |
| 10 | PRD에 정의가 없던 부분을 임의 결정 | 마감 지난 프로젝트는 흐리게 뒤로, 만료 메모는 흐리게 표시, 태스크 `category`는 Task List에 대응 |

## 8. 미확인 사항 및 사용자 조치 필요 항목

### 8.1 사용자가 직접 해야 하는 일
1. Apps Script 편집기에서 `setupToken()` 실행 → 권한 승인 → 실행 로그의 **API 토큰** 복사
2. `dashboard.html` → ⚙️ 설정 → 토큰 입력 → **🔌 연결 테스트** → 저장
3. (선택) 구글 캘린더 임베드 URL 또는 캘린더 ID(이메일) 입력

### 8.2 실제 구글 환경에서 확인이 필요한 부분 (로컬에서는 검증 불가)
- 시트 읽기·쓰기, Tasks API 호출, 브라우저 CORS 동작.
- **태스크 마감일 하루 어긋남 여부**: 구글 태스크는 마감일을 날짜만 저장한다. 어긋나면 `GAS/Tasks.gs`의 `dueToRfc3339_` 시간대 처리를 수정한다.
- **시트 ID**: `Config.gs`는 PRD의 ID(`1IJ4Eq…`)를 사용 중. 엑셀을 새 시트로 변환해 쓰면 ID 변경 후 재배포 필요.
- 비공개 캘린더는 구글에 로그인된 브라우저에서만 임베드가 표시됨.

### 8.3 알려진 한계
- 토큰은 브라우저 `localStorage`에 저장되므로 공용 PC에서는 사용하지 않는다.
- 토큰을 아는 사람은 배포 계정 권한으로 해당 시트와 태스크를 읽고 쓸 수 있다.
- 구글 캘린더 임베드는 표시 전용이며 일정 편집은 `↗ 구글 캘린더` 버튼으로 이동해서 한다. 대시보드의 프로젝트 막대는 구글 캘린더 본체에는 나타나지 않는다.
- 기업 정책으로 "모든 사용자" 배포가 막힌 경우 "조직 내 모든 사용자"로 배포해야 하며, 이때 브라우저의 구글 로그인이 필요하다.
